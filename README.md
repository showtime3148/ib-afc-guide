# IB AFC 길잡이

IB DP 후보학교 신청서(Application for Candidacy, AFC)를 처음 작성하는 학교를 위한 웹앱입니다.
예당고등학교(전남 보성)가 2026년 10월 후보학교를 신청하며 겪은 과정을 정리했습니다.

## 기능
- **단계별 체크리스트**: 신청 전 준비부터 제출 이후까지 35개 항목, 진행률은 브라우저에 저장
- **항목별 가이드**: AFC 문항 영·한 대조, 작성 팁, 예당고 예시 답변(영문·국문), 검색
- **문제 해결**: 실제로 막혔던 오류 메시지와 해결 방법
- **AI 영문 도우미**: 학교 상황을 한국어로 적으면 문항에 맞는 영문 초안과 한국어 대역 생성

## 구조
빌드 과정이 없는 정적 사이트입니다.
- `index.html`, `style.css`, `app.js` — 화면
- `guide.js` — AFC 문항과 예시 답변 데이터
- `content.js` — 체크리스트, 문제 해결, 필수 서류 데이터
- `api/draft.js` — Vercel 서버리스 함수 (AI 도우미)

## 배포 (Vercel)
1. 이 저장소를 Vercel 프로젝트로 가져옵니다 (Framework: Other).
2. AI 도우미를 쓰려면 프로젝트 환경 변수에 `ANTHROPIC_API_KEY`를 넣습니다. 없으면 AI 버튼 대신 "프롬프트 복사"만 동작합니다.
3. (선택) `ANTHROPIC_MODEL`로 모델을 바꿀 수 있습니다.

## 내용 고치기
문항이나 팁을 고치려면 `guide.js`, `content.js`만 수정하면 됩니다.
IB 양식과 절차는 바뀔 수 있으니 최신 안내는 IB 공식 자료로 확인하세요.
